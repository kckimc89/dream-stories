# 꿈나라 동화책 V1.2

GitHub Pages에 이 ZIP의 압축을 푼 파일만 올립니다. iPad Safari에서 Pages 주소를 열고 홈 화면에 추가하세요. 홈 화면 앱에서 원본 음원 추가하기를 눌러 파일 앱에 저장된 MP3를 선택합니다. IndexedDB에 원본을 저장하며 서버로 전송하지 않습니다. 최초 온라인 설치 후 오프라인 재생을 시험하세요. iPad 저장소 삭제 또는 시스템 정책에 의해 파일이 사라질 수 있으므로 원본은 파일 앱에도 보관하세요.

## 출처
홍제천 도롱이 가족을 부탁해 — 서대문구 기후환경과, 2022년. [공식 게시물](https://www.sdm.go.kr/news/news/notice.do?mode=view&sdmBoardSeq=276003)은 공공누리 제3유형(출처표시·변경금지)을 표시합니다. 별도 MP3의 직접 다운로드 및 PDF 내 음원과의 일치 여부는 확인하지 못했으므로 이 배포판에는 외부 음원과 표지 및 변환 음원을 넣지 않았습니다. 공식 MP3를 개인 감상용으로 추가하세요.

아이패드 실기기 및 잠금화면 재생은 미검증입니다.

V1.2: 파일 선택 제한 해제 및 파일 헤더 검사. 기존 IndexedDB 유지.
