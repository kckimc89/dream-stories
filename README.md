# 꿈나라 동화책 V2.6

- 기존 V2.5 창작동화 13편의 제목·본문·ID 및 기존 음원 IndexedDB, 환경설정과 감상 기록의 키를 보존했습니다.
- 새 창작동화: 뼈 나라의 튼튼한 기둥, 자석 왕국의 비밀. 새 과학 모식도 4개(골격과 성장판, 자기장, 혈액순환, 무지개 굴절과 반사).
- library/분야/동화ID/story.js 및 같은 폴더의 삽화로 관리합니다. 기존 SVG와 과학 설명 JPG는 원본을 유지하며, 동화 JPG는 높은 품질의 WebP가 충분히 작고 품질 기준을 통과할 때만 변환했습니다.
- 그림은 삽화 탭을 열 때만 화면에 로딩되지만, 최초 온라인 실행 시 서비스 워커는 전체 창작동화와 삽화를 검증하고 미리 캐시에 저장합니다. 오프라인 확인 버튼으로 준비 상태를 확인하세요. 기기 음성은 로컬 한국어 음성을 설치해야 인터넷 없이 재생할 수 있으며 화면 잠금 시 구연이 멈출 수 있습니다. 브라우저/OS의 저장 공간 정리로 캐시 및 기기 데이터가 삭제될 수 있습니다.

## 설치
기존 저장소의 같은 위치에 ZIP을 압축 해제한 전체 내용을 폴더 구조 그대로 업로드합니다. library 폴더를 평평하게 풀어 올리지 마세요. 기존 루트의 이미지 파일은 당장 삭제할 필요가 없습니다. GitHub Pages 배포 완료 후 기존 앱에서 새 버전을 불러오고 오프라인 확인이 완료될 때까지 인터넷에 연결하세요. 기존 홈 아이콘이나 사이트 데이터를 삭제하지 마세요.

## 이후 콘텐츠 업데이트
새 동화 파일은 library/<분야>/<고유 ID>/ 아래에 둡니다. index.html의 동화 스크립트 목록에 등록하고, version.json, sw.js의 버전/캐시 이름 및 offline-manifest.json의 파일 목록·SHA-256을 함께 갱신합니다. 같은 버전 번호로 다른 파일을 배포하지 마세요. 기존 파일은 변경되지 않았다면 다시 업로드하지 않아도 됩니다. 새 서비스 워커는 이전 캐시에 있는 동일 해시의 파일을 재사용합니다. 완전한 ZIP은 별도로 보관하세요.

## 범위
ZIP은 앱과 내장 창작동화 전체 백업입니다. 기기에 등록된 외부 원본 음원·사용자 작성 동화·감상 기록을 별도 내보내는 기능은 이번 버전에 추가하지 않았습니다.
